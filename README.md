# Marcos Vissio — Engineering Portfolio

A bilingual (English-first, Spanish) professional portfolio for Marcos Vissio, Senior Full Stack Software Engineer based in Mendoza, Argentina. It is intended to demonstrate hands-on engineering, software architecture, and technical leadership for international remote-first opportunities.

## Status

Phase 0 is complete: the repository contains product, architecture, engineering, and agent-continuity documentation only. No application code or dependencies have been added.

## Product direction

The MVP will establish a polished landing experience, verified professional profile and experience content, selected projects, contact/resume access, and bilingual foundations. The Architecture Lab is the primary differentiator and is planned as a focused follow-up increment rather than an all-at-once launch.
